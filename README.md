# jeffbulmer.github.io

Personal site for Jeff Bulmer, built with Angular and published to GitHub Pages.

```bash
npm install
npm start          # http://localhost:4200
npm run deploy     # build and push to the gh-pages branch
```

Drop a resume PDF at `src/assets/cv/resume.pdf` to make the header button work.
